Политика конфиденциальности «Shape Tracker»

Дата обновления: 16 июля 2026
Разработчик: Галиев Алексей Юрьевич
Контакт: alexeygalievv@gmail.com

Настоящая Политика описывает, какие данные обрабатываются в мобильном приложении «Shape Tracker» и с какой целью. Используя приложение, вы подтверждаете, что ознакомились с Политикой.

1. Общие положения

Shape Tracker — дневник тренировок с опциональной облачной синхронизацией, AI-планом (Pro) и отслеживанием прогресса. Мы собираем только данные, необходимые для работы этих функций.

2. Какие данные обрабатываются

  • Данные аккаунта — email и идентификаторы при входе по email/паролю или Sign in with Apple (Firebase Authentication).
  • Профиль — имя, возраст, пол, рост, вес, активность, предпочтения.
  • Тренировки — упражнения, подходы, вес, повторения, время, заметки.
  • Замеры и цели.
  • Фото прогресса — добавляете вы; файлы хранятся на устройстве.
  • Недельный план — упражнения и расписание.
  • Анкета для AI-плана — цели, опыт, травмы/ограничения, оборудование, длительность и т.п. при генерации плана.
  • Статус подписки Pro — через Apple; данные банковской карты нам не передаются.
  • Технические данные — версия приложения, платформа, идентификатор запроса к серверу генерации.

3. Где хранятся данные

  • На устройстве — локально для работы офлайн.
  • В облаке — при входе в аккаунт данные могут синхронизироваться в Google Firebase (Firestore) по вашему user ID.
  • На нашем сервере — при генерации AI-плана параметры анкеты и профиля отправляются на сервер; полная история тренировок для этого не передаётся без необходимости.

4. Сторонние сервисы

  • Google Firebase — вход и синхронизация.
  • Apple — Sign in with Apple, подписки App Store.
  • AI-провайдеры — сервер может передавать параметры плана (цели, травмы, опыт) для генерации текста программы.

Рекламного трекинга и продажи персональных данных нет.

5. Цели обработки

  • Дневник, статистика, напоминания.
  • Синхронизация между устройствами.
  • AI-план и рекомендации (Pro).
  • Проверка подписки.
  • Стабильность сервиса.

6. Разрешения устройства

  • Фото / камера — для фото прогресса.
  • Уведомления — по вашему выбору.

7. Аккаунт и подписка

Оформление Pro требует аккаунта в приложении. Оплата — через Apple. «Восстановить покупки» использует историю транзакций Apple ID.

8. Удаление данных

  • Удаление отдельных записей в приложении.
  • Сбросить все данные в настройках.
  • Удаление аккаунта — удаляет учётную запись Firebase и облачные данные.
  • Удаление приложения — локальные данные с устройства.

Удаление аккаунта не отменяет подписку App Store автоматически — отмена в Настройки → Apple ID → Подписки.

9. Дети

Приложение не предназначено для детей младше 13 лет.

10. Безопасность и срок хранения

Передача данных — по HTTPS; облако — Firebase. Данные хранятся, пока существует аккаунт или пока вы их не удалите.
